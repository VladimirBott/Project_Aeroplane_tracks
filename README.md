# Aeroplane Tracker

Программа для отслеживания самолетов в реальном времени через открытые API.

## Возможности

- 📍 Загрузка данных о самолетах по стране
- 🏆 Получение топ N самолетов по высоте
- 🇺🇸 Фильтрация по стране регистрации
- 💾 Сохранение и загрузка данных в JSON
- 📊 Статистика по данным
