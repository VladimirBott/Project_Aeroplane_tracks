##  Возможности

###  Получение данных в реальном времени
- Отслеживание самолетов по стране регистрации
- Получение актуальных данных с OpenSky Network API
- Отображение позиции, высоты, скорости и курса воздушных судов

###  Управление данными
- Сохранение полученных данных в JSON формате
- Поиск самолетов по стране регистрации в сохраненных данных
- Топ N самолетов по высоте полета
- Удаление конкретных самолетов или всех данных
- Статистика по сохраненным данным

###  Статистика и анализ
- Общее количество самолетов
- Распределение по странам регистрации
- Статистика по высоте и скорости
- Самые частые страны происхождения

###  Пользовательский интерфейс
- Интуитивно понятное консольное меню
- Цветовое оформление и форматирование
- Подробный вывод информации о самолетах
- Логирование всех операций

##  Технологии

- **Python 3.8+** - основной язык программирования
- **OpenSky Network API** - источник данных о воздушных судах
- **JSON** - формат хранения данных
- **Pytest** - фреймворк для тестирования
- **unittest.mock** - мокирование для изолированного тестирования
- **Logging** - система логирования операций


##  Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/VladimirBott/Project_Aeroplane_tracks.git
cd aeroplane-tracker
```

### 2. Создание виртуального окружения
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate     # Windows
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск приложения
```bash
python main.py
```

##  Тестирование

Проект включает полный набор unit-тестов:

### Запуск всех тестов
```bash
pytest tests/ -v
```

### Запуск конкретных тестов
```bash
# Тесты для класса Aircraft
pytest tests/test_aeroplanes.py -v

# Тесты для JSON обработчика
pytest tests/test_json_handler.py -v

# Тесты для пользовательского интерфейса
pytest tests/test_user_interface.py -v
```

##  Архитектура

### Модель данных (Aircraft)
Используется `@dataclass` с валидацией:
- Все поля строго типизированы
- Автоматическая валидация при создании
- Поддержка сравнения самолетов по высоте
- Методы для определения состояния (набор высоты, снижение и т.д.)

### Обработка файлов
Абстрактная архитектура с поддержкой различных форматов:
- Базовый класс `BaseFileHandler`
- Реализация `JSONFileHandler`
- Легкое добавление новых форматов (CSV, SQLite и т.д.)

### Безопасность и надежность
- Валидация всех входных данных
- Обработка ошибок API и файловых операций
- Атомарные операции записи для избежания повреждения данных
- Логирование всех операций
